## 随机掉落调用边界

`sub_45E5A0` 的第一个参数会按 `RandProp.角色ID` 查询 `0x00578D18` 表。已确认调用点：

| 地址 | 行为 | 说明 |
| --- | --- | --- |
| `0x0043F6B1` -> return `0x0043F6B6` | 调用 `sub_45E5A0(..., 0.0)` | 普通击败/血量清空时的一次掉落 |
| `0x0042CD6B` | 调用 `sub_45E5A0(..., score)` | 连招结束后的二次掉落路径 |
| `0x0045E6F1` -> return `0x0045E6F6` | `rand` 后进行物品掉落 gate 判定 | 可用于限定敌人基础物品掉落概率判定 |

## 掉落选物关键地址

`sub_45E390(a1, a2)` 中，只有 `a2 == -1` 或 `a2 == 0xFFFF` 时才会随机决定物品类型。

| 地址 | 指令/行为 | 说明 |
| --- | --- | --- |
| `0x0045E417` | `mov esi, 1Eh` | 生成 Type 30 |
| `0x0045E447` | 设置 Type 10 或 Type 20 | 未命中 Type 30 后的分支 |
