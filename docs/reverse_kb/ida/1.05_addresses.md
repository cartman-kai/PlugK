## 掉落选物关键地址

`sub_452200(a1, a2)` 中，只有 `a2 == -1` 或 `a2 == 0xFFFF` 时才会随机决定物品类型。

| 地址 | 指令/行为 | 说明 |
| --- | --- | --- |
| `0x00452271` | `mov edi, 1Eh` | 生成 Type 30 |
| `0x004522E6` | 设置 Type 10 或 Type 20 | 未命中 Type 30 后的分支 |

## `sub_452420` 内部调用 `sub_452200` 的返回地址

这些返回地址用于把 hook 限定在敌人随机掉落路径内：

- `0x00452630`
- `0x00452641`
- `0x00452652`
- `0x00452663`

## Hook 注意事项

- 不要把 `sub_452200` 的所有调用都当作敌人随机掉落。
- 敌人拾取到的已有物品吐出逻辑不应归入随机掉落倾向优化。
- 修改具体物品 ID 时，优先在 `sub_452420` 内部调用返回点做边界判断。
