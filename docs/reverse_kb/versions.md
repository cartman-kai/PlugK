# 版本差异

游戏目前关注两个版本：`1.05` 与 `2.01`。

## 总体差异

- 两个版本反汇编代码略有差异，虚拟地址不同。
- 主要游戏逻辑基本相同，hook 注入时通常可以用相似方式寻找对应函数和逻辑。
- “相似”不代表可直接复用地址；每个版本都需要单独确认函数入口、全局变量和关键返回地址。
- 当前 IDA Pro 中链接的是 `1.05` 版本程序，应优先把 1.05 地址整理完整，再补充 2.01 对照。

## 编译器与编码

- 游戏采用 VC++ 6.0 编译。
- 游戏内文本编码主要为 GBK/GB2312。
- 早期 Excel 导出的模板数据为 GB2312 编码的 tab 分隔 txt 文本。

## 难度编号

`1.05` 具有 4 个难度，内部编号 `0-3`。

`2.01` 具有 5 个难度，内部编号 `0-4`。

| 内部编号 | 玩家难度 |
| --- | --- |
| 0 | 低 |
| 1 | 中 |
| 2 | 高 |
| 3 | 真正的战斗 |
| 4 | 英雄无悔 |

## 地址迁移建议

从 1.05 移植到 2.01 时，优先用以下特征定位：

- 函数调用链路，而不是硬编码地址。
- 对同一数据表的访问模式。
- 难度变量、表头结构、物品类型常量等稳定特征。
- 调用返回地址，用于区分共享函数的不同上游路径。
