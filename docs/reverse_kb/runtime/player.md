# 角色运行时内存

## 角色对象入口

角色主要信息通过一个全局地址保存指针，指向角色对象。

| 版本 | 全局地址 | 说明 |
| --- | --- | --- |
| 1.05 | `0x00558AC4` | 保存角色对象指针 |
| 2.01 | `0x00589A44` | 保存角色对象指针 |

2.01 动态调试确认 `[0x00589A44]` 指向角色对象。

## 物品容器偏移

1.05 与 2.01 角色对象中已经确认的物品容器偏移一致。

| 偏移 | 含义 |
| ---: | --- |
| `+0xA0` | 物品池指针数组 |
| `+0xA4` | 背包，50 个 `int32` 物品池索引 |
| `+0x184` | 快捷/道具栏，12 个 `int32` 物品池索引 |
| `+0x1B4` | 装备镶嵌位，12 个 `int32` 物品池索引 |
| `+0x1E4` | 护身石位，6 个 `int32` 物品池索引 |
| `+0x1FC` | 仓库，50 个 `int32` 物品池索引 |

## 容器槽位值

- 空位：`-1`。
- 非空：物品池索引。

## 技能链表

1.05 与 2.01 角色对象中的技能链表偏移已共用验证。

| 偏移 | 含义 |
| ---: | --- |
| `+0x364` | 技能链表头节点指针 |

技能链节点当前确认字段：

| 节点偏移 | 含义 |
| ---: | --- |
| `+0x00` | next 指针 |
| `+0x08` | 技能 ID |

已知用途：

- 一键洗技能功能通过该链表枚举当前角色已学习技能。
- 必杀技快捷释放通过该链表确认角色是否拥有对应必杀技技能 ID。
- 释放技能或必杀技时，游戏函数使用的是招式 ID；技能链中保存的是技能 ID，两者不要混用。

## 物品对象字段

| 偏移 | 含义 |
| ---: | --- |
| `+0x18` | 物品 ID |
| `+0x1C` | 数量 |
