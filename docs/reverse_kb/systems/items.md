# 物品系统

## 物品类型

游戏中的物品类型目前整理如下：

| 类型 | 含义 |
| ---: | --- |
| 0 | 金钱 |
| 10 | 药品 |
| 20 | 可投掷物品 |
| 30 | 可镶嵌的宝石 |
| 35 | 疑似高难度下才会出现的宝石 |
| 40 | 任务道具 |
| 50 | 护身石，不需要镶嵌，可直接佩戴 |
| 60 | 特殊标记类道具分类 |
| 100 | 特殊宝石，部分特殊宝石可以把镶嵌宝石转换为护身石 |

## 物品池与容器

角色对象中多个容器槽位保存的是物品池索引，而不是直接保存物品对象。

- 容器空位为 `-1`。
- 非空值为物品池索引。
- 物品池索引指向物品对象。
- 物品对象中 `+0x18` 为物品 ID。
- 物品对象中 `+0x1C` 为数量。

已确认 1.05 与 2.01 的容器偏移一致，详见 [角色运行时内存](../runtime/player.md)。

## 物品模板名称

运行时 `PropMdl` 记录可反查物品显示名称。记录第 4 个 dword，即 `record + 0x0C`，指向一组文本指针；其中第一个指针 `ptrs[0]` 指向物品名，字符串编码为 GBK。

表头、记录结构和字段说明详见 [数据表与资源](../data_tables.md)。

## 地面物品名称显示

1.05 中 `sub_4127D0` 负责物品名称显示。该函数会通过物品模板生成 GBK 名称字符串，随后在 `0x004128AE` 调用 `sub_4CC4B0` 创建文字节点。

动态调试已用 GBK 字符串 `极品紫水晶` 精确断在 `sub_4CC4B0` 入口，确认返回地址为 `0x004128B3`，即来自 `sub_4127D0` 的调用点。将 `sub_4127D0` 调用前写入文字节点 `+0x0C` 的样式参数从 `0` 改为 `1` 后，地面物品名称文字背景消失，文字仍正常显示。

后续跟踪确认，`sub_4CC4B0` 只创建文字节点，节点字段 `+0x0C` 会在 `sub_4CC440` 中决定是否把背景参数传给 `sub_4B1DF0`：当 `+0x0C == 1` 时传入 `0`，地面物品名称无背景；当该字段为其它值时会传入 `1`，背景/边框会出现。`+0x10`、`+0x14` 未观察到会改变文字颜色。

文字颜色不由 `sub_4CC4B0` 的三个样式参数直接决定。地面浮动文字管理器由 `dword_55C1F8` 指向，构造函数为 `sub_4CC0C0`，其绘制路径为 `sub_4CC440 -> sub_4B1DF0 -> sub_4B25A0`。`sub_4B25A0` 先调用 `SetTextColor(hdc, this[24])`，即默认颜色来自文字管理器对象 `this + 0x60`。动态调试中将当前 `dword_55C1F8 + 0x60` 从白色改为 `0x0000FFFF` 后，地面物品名称变为黄色，且无背景效果保持不变。

`sub_4B25A0` 还支持字符串内嵌颜色控制码，会检测并移除 `$G`、`$Y`、`$B`、`$R`、`$W`、`$H` 等短标记，然后切换到 `0x00545C48` 附近的一组 `COLORREF` 颜色值。

plugK 的 1.05 “掉落物品显示颜色优化”实现没有长期修改 `dword_55C1F8 + 0x60`，因为该颜色会影响背包悬停物品、NPC 名字等同层文字。实现路径为：hook `sub_4127D0` 读取地面物品对象 `this+0x81` 的 `PropMdl` 记录，按记录字段 `type` 与 `quality` 判定是否需要染色；hook `sub_4CC4B0` 仅给本次创建的物品名字符串加内部标记；hook `sub_4B25A0` 在绘制该标记字符串时临时设置 `this+0x60`，调用原函数时传入去标记后的字符串，返回后立即恢复旧颜色。

`sub_4B25A0` / `sub_4C58F0` 是共享文字输出函数，不能由多个功能各自 `MH_CreateHook`。当前 plugK 由地面物品名称模块统一安装该 DrawText hook：掉落物品名称染色在标记字符串路径内处理，敌人血量显示通过同一 hook 的调用返回地址边界追加 HP 行；敌人血量模块只单独 hook 敌人名称绘制函数以取得当前敌人对象。

2.01 静态对照确认同构链路：`sub_41A500` 负责地面物品名称显示，读取 `this+0x81` 的 `PropMdl` 记录，经 `sub_4E4D90(record, 0)` 取名称后调用 `sub_4E1270` 创建文字节点；`sub_4E1200` 遍历节点并按 `node+0x0C` 控制背景；最终文字输出函数 `sub_4C58F0` 仍使用文字管理器对象 `this+0x60` 作为默认 `SetTextColor` 颜色，并支持同类内嵌颜色码。2.01 玩家可见效果仍需动态验证。

当前品质颜色映射：`1-2` 蓝色，`3-4` 绿色，`5-6` 橙色，`7` 金色，`8` 赤铜色，`9+` 紫色。1.05 对 `type=30/50` 生效；2.01 对 `type=30/35/50` 生效，其中 `type=35` 的自然生成路径仍需结合资源表和动态调试确认。

## 随机类型生成边界

随机掉落选物函数只有在类型参数为 `-1` 或 `0xFFFF` 时，才会先随机决定物品类型。

如果调用方显式传入某个物品类型，则应按指定类型查询物品表，不应归入“随机类型倾向”逻辑。
