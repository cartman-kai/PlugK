# 物品系统

## 物品类型

游戏中的物品类型目前整理如下：

| 类型 | 含义 |
| ---: | --- |
| 0 | 金钱 |
| 10 | 药品 |
| 20 | 可投掷物品 |
| 30 | 可镶嵌的宝石 |
| 35 | 疑似高难度下才会出现的宝石 |
| 40 | 任务道具 |
| 50 | 护身石，不需要镶嵌，可直接佩戴 |
| 60 | 特殊标记类道具分类 |
| 100 | 特殊宝石，部分特殊宝石可以把镶嵌宝石转换为护身石 |

## 物品池与容器

角色对象中多个容器槽位保存的是物品池索引，而不是直接保存物品对象。

- 容器空位为 `-1`。
- 非空值为物品池索引。
- 物品池索引指向物品对象。
- 物品对象中 `+0x18` 为物品 ID。
- 物品对象中 `+0x1C` 为数量。

已确认 1.05 与 2.01 的容器偏移一致，详见 [角色运行时内存](../runtime/player.md)。

## 物品模板名称

运行时 `PropMdl` 记录可反查物品显示名称。记录第 4 个 dword，即 `record + 0x0C`，指向一组文本指针；其中第一个指针 `ptrs[0]` 指向物品名，字符串编码为 GBK。

表头、记录结构和字段说明详见 [数据表与资源](../data_tables.md)。

## 随机类型生成边界

随机掉落选物函数只有在类型参数为 `-1` 或 `0xFFFF` 时，才会先随机决定物品类型。

如果调用方显式传入某个物品类型，则应按指定类型查询物品表，不应归入“随机类型倾向”逻辑。
